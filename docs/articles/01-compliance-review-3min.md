## 一、背景与痛点

政府采购文件编制是采购流程中的核心环节，传统人工审查模式面临三大痛点：

| 痛点 | 具体表现 |
|------|---------|
| **效率低** | 一份采购文件人工审查需数小时甚至数天，采购旺季审查压力巨大 |
| **合规风险高** | 审查质量依赖个人经验，容易遗漏排他性条款、政策偏差等合规风险 |
| **监督难** | 审查过程缺乏留痕，事后追溯困难，全过程监督难以落地 |

据统计，行业平均采购文件错误率约10%，因合规问题导致的质疑投诉占比居高不下。

---

## 二、解决方案：采购文件合规检测智能体

彩翼平台推出的**采购文件合规检测智能体**，基于大语言模型+规则引擎双路审查机制，实现采购文件的**秒级智能合规检测**。

### 核心能力

```
采购文件上传 → 智能解析 → 多维度合规检测 → 分级批注 → 合规评分 → 修改建议 → 审查报告
```

### 检测维度

| 检测维度 | 检测内容 |
|---------|---------|
| **合规性检测** | 法律法规符合性、政府采购政策落实、排他性条款识别 |
| **合理性检测** | 评分标准合理性、资格条件合理性、技术参数合理性 |
| **错敏词检测** | 错别字、敏感词、不规范表述 |
| **格式规范性** | 文件结构完整性、必备条款覆盖、格式标准 |
| **政策偏差识别** | 中小企业政策、节能环保政策、进口产品政策落实情况 |

---

## 三、核心技术方案

### 1. 规则引擎+大模型双路审查

- **规则引擎**：基于预置的审查规则库，进行确定性规则匹配，确保基础合规问题100%覆盖
- **大模型审查**：基于LLM的语义理解能力，识别规则难以覆盖的隐性合规风险（如变相排他、倾向性表述）
- **双路融合**：规则引擎结果与大模型结果融合，输出最终审查结论

### 2. 法规知识库RAG检索

- 构建10万+法规文档的RAG检索系统（Milvus+Neo4j双引擎）
- 审查时自动检索相关法规条款，提供判断依据
- 支持法规时效性校验（现行/已废止/已修订）

### 3. 分级批注与合规评分

- 问题按严重程度分为**高/中/低**三级
- 高风险问题：违法违规、排他性条款，必须修改
- 中风险问题：政策偏差、合理性存疑，建议修改
- 低风险问题：格式、表述、错别字，可选修改
- 综合合规评分（0-100分），直观反映文件合规水平

## 五、全过程监督

智能体不仅提升审查效率，更实现了采购文件的**全过程监督**：

1. **事前预防**：文件发布前智能检测，从源头规避合规风险
2. **事中留痕**：审查过程全记录，问题修改可追溯
3. **事后分析**：审查数据统计分析，识别高频问题，优化文件范本
4. **监管支撑**：为监管部门提供批量智能检测能力，提升监管覆盖面
