## 一、背景：从通用到专项

采购文件合规检测智能体上线后，已实现采购文件的通用合规检测。但在实际应用中发现，**不同品目类别的采购文件具有显著的行业特性和专项合规要求**，通用检测规则难以覆盖所有细分场景的深度合规需求。

其中，**信息化项目**（软件开发、系统集成、IT设备采购等）具有以下特点：
- 技术参数复杂，容易出现倾向性、排他性条款
- 资质要求特殊（CMA、CMMI、ISO等认证）
- 评分标准容易设置不合理的技术加分项
- 涉及信息安全、数据安全等专项合规要求

因此，彩翼平台推出**采购文件检测智能体（增强版）**，在通用检测基础上，新增**信息化项目专项合规检测标准**，实现从"通用检测"到"专项深审"的升级。

## 二、信息化项目专项检测标准

### 1. 技术参数合规性检测

| 检测项 | 检测内容 | 风险等级 |
|--------|---------|---------|
| **指定品牌/型号** | 技术参数中是否指定特定品牌、型号、产地 | 高 |
| **倾向性参数** | 技术参数是否指向特定供应商的产品特性 | 高 |
| **排他性条款** | 是否设置不合理的技术门槛排斥潜在供应商 | 高 |
| **参数必要性** | 技术参数是否与项目实际需求匹配，有无过度要求 | 中 |
| **参数可验证性** | 技术参数是否可客观验证，有无模糊表述 | 中 |

### 2. 资质要求合规性检测

| 检测项 | 检测内容 | 风险等级 |
|--------|---------|---------|
| **CMA证书要求** | 检验检测机构资质认定（CMA）要求是否合理 | 中 |
| **CMMI等级要求** | 软件能力成熟度模型集成（CMMI）等级要求是否与项目规模匹配 | 中 |
| **ISO认证要求** | ISO9001/ISO27001/ISO20000等认证要求是否合理 | 低 |
| **资质与项目匹配度** | 要求的资质是否与信息化项目实际需求相关 | 中 |
| **资质门槛合理性** | 是否设置过高资质门槛限制中小企业参与 | 高 |

### 3. 评分标准合规性检测

| 检测项 | 检测内容 | 风险等级 |
|--------|---------|---------|
| **技术分占比** | 技术分占比是否符合政府采购规定 | 高 |
| **价格分占比** | 价格分占比是否合理 | 中 |
| **评分项客观性** | 评分项是否可客观量化，有无主观打分空间过大 | 中 |
| **业绩要求合理性** | 类似项目业绩要求是否与项目规模匹配 | 中 |
| **人员要求合理性** | 项目团队人员资质、数量要求是否合理 | 低 |

### 4. 信息安全专项检测

| 检测项 | 检测内容 | 风险等级 |
|--------|---------|---------|
| **数据安全要求** | 是否明确数据安全、个人信息保护要求 | 中 |
| **等保要求** | 信息系统等级保护要求是否合理 | 中 |
| **国产化要求** | 国产化适配要求是否符合政策规定 | 中 |
| **源代码交付** | 源代码交付、知识产权归属约定是否清晰 | 低 |

## 三、专项检测的技术实现

### 1. 品目自动识别

智能体自动识别采购文件的品目类别（信息化项目/货物类/服务类/工程类），自动匹配对应的专项检测标准。

```
文件上传 → 品目识别（NLP分类） → 匹配专项检测规则 → 通用检测+专项检测 → 融合输出
```

### 2. 专项规则库

针对信息化项目，构建专项检测规则库，包含：
- 信息化项目常见排他性参数模式库
- 资质要求合理性判断规则
- 评分标准合规性规则
- 信息安全专项检查清单

### 3. 大模型深度语义审查

对于规则难以覆盖的隐性风险（如变相指定品牌、倾向性表述），利用大模型的语义理解能力进行深度审查：
- 技术参数与特定产品特性的相似度分析
- 资质要求与项目需求的相关性判断
- 评分标准的公平性评估

## 四、应用价值

| 维度 | 通用检测 | 通用+专项深审 | 提升 |
|------|---------|-------------|------|
| 检测覆盖范围 | 通用合规问题 | 通用+信息化专项问题 | 显著扩大 |
| 排他性条款识别率 | ~70% | **90%以上** | +20% |
| 资质合理性判断 | 基础判断 | **专项深度判断** | 质的提升 |
| 信息化项目适配度 | 通用 | **高度适配** | 显著提升 |
| 审查报告专业性 | 通用建议 | **专项修改建议** | 更具操作性 |

## 五、后续规划

信息化项目专项检测标准上线后，彩翼平台将持续扩展专项检测范围：

1. **工程类项目专项检测**：工程建设项目的资质、评分、技术参数专项标准
2. **服务类项目专项检测**：服务采购的人员、方案、报价专项标准
3. **医疗设备专项检测**：医疗设备采购的注册证、技术参数专项标准
4. **家具类专项检测**：家具采购的环保标准、材质要求专项标准

最终实现**全品目类别专项检测标准覆盖**，为不同类型采购项目提供精准的深度合规审查。
