## 一、背景：AI赋能政府采购的广州实践

随着新一代人工智能技术的快速发展，"AI+政务"已成为数字政府建设的重要方向。政府采购作为政务服务的重要组成部分，具有流程长、环节多、合规要求高、数据量大等特点，是AI技术应用的典型场景。

广州市政府采购中心（广州交易集团旗下）积极探索"AI+政府采购"融合应用，于**2025年4月8日**正式上线全国首个公共采购智能体协同管理平台——**"彩翼"平台**，以人工智能技术重塑政府采购全流程，推动政府采购从"电子化"向"智能化"跨越式转变。

---

## 二、彩翼平台整体架构

### 平台定位

彩翼公共采购智能体协同管理平台是面向公共采购四类核心主体（**监管部门、采购人、代理机构、供应商**）的一站式AI协同管理平台，依托彩翼人工智能联合实验室自主研发。

### 五大层级架构

| 层级 | 核心能力 |
|------|---------|
| **生态应用层** | 自研智能体、第三方智能体、第三方增值服务、可信数据空间 |
| **应用管理层** | 账户权限、智能体接入、定价支付、日志管理、对账系统 |
| **平台层** | OCR识别、思维链、任务编排、RAG检索、LLM推理、规则推理 |
| **模型基座层** | 主流大模型接入、算力调度、模型管理、视觉识别、OCR |
| **数据基座层** | 数据托管、数据治理、共享交换、数据可视化、六大数据库 |

### 六大核心功能

1. **自研智能体应用支撑** — 为自研智能体提供国产算力部署、模型研发、智能体调度
2. **第三方智能体接入服务** — 创新构建智能体准入标准，五级审核全生命周期管控
3. **生态级服务聚合门户** — 整合第三方智慧解决方案，构建"数据-工具-场景"一体化资源池
4. **可信数据空间** — 基于区块链的数据交换网络，跨部门数据安全确权与按需共享
5. **交易系统SaaS服务** — 集成自研公共采购交易系统，面向代理机构提供SaaS服务
6. **异构算力聚合调度** — 聚合国产算力，精准匹配与资源优化算法提升算力利用率

## 三、已部署的12个智能体

彩翼平台已部署**12个智能体**，覆盖采购全流程高频场景：

### 采购文件类（3个）

| 智能体 | 功能 | 状态 |
|--------|------|------|
| **采购需求调查智能体** | 需求规范性检查、技术参数验证、价格预测、供应商格局分析 | 测试验收 |
| **采购文件辅助编制智能体** | 资格条件、评分标准、合同条款等核心章节自动生成 | 已上线 |
| **采购文件合规检测智能体** | 发布前合规检测，识别违法违规和排斥限制竞争问题 | 已上线 |

### 投标服务类（2个）

| 智能体 | 功能 | 状态 |
|--------|------|------|
| **投标合规检测智能体（审查）** | 资格性、符合性、商务技术逐供应商核查，提前识别废标风险 | 已上线 |
| **投标合规检测智能体（模拟评审）** | 投标前模拟评审，提前优化投标策略 | 已上线 |

### 评审监管类（2个）

| 智能体 | 功能 | 状态 |
|--------|------|------|
| **采购项目审计（稽核）智能体** | 串围标风险检测+采购文件审查，自动形成证据链 | 测试验收 |
| **辅助评审智能体** | 专家辅助评审、评分辅助、异常行为识别 | 规划中 |

### 综合业务类（4个）

| 智能体 | 功能 | 状态 |
|--------|------|------|
| **质疑回复处理智能体** | 质疑函解析、智能分类、法规检索、回复生成 | 已上线 |
| **智能咨询助手** | 政策法规、业务知识、操作流程多模态咨询 | 已上线 |
| **预算审查智能体** | 预算申报表智能解析、价格合理性审查 | 已上线 |
| **合同审查智能体** | 合同主体、标的范围、价款支付、履约验收审查 | 测试验收 |

### 专项服务类（1个）

| 智能体 | 功能 | 状态 |
|--------|------|------|
| **询价比价智能体** | 文件解析、智能比价、报告生成 | 需求评估 |

> 注：此外还有家具比价、阳光商城比价、上架审核、智能搜索等专项智能体已完成一期开发。

## 四、应用成效

### 整体成效

| 指标 | 数据 |
|------|------|
| 涉及项目交易额 | 超10亿元 |
| 人均工作效率提升 | 300% |
| 采购成本节约 | 30% |
| 无效投标率降低 | 35% |
| 战略合作单位 | 26家 |

### 各智能体成效

**采购文件合规检测智能体**：
- 招标文件错误率从10%降至1%以内
- 文件更正比例下降40%
- 单文件审查从数小时缩短至3分钟

**质疑回复处理智能体**：
- 处理时间从2-3个工作日缩短至1-2小时
- 投诉率同比下降超200%
- 质疑升级为投诉比例从10%降至5%
- 法规引用准确率从90%提升至98%

**投标合规检测智能体**：
- 供应商废标率从15%-20%降至5%以内
- 投标文件编制从3-5天压缩至3小时
- 中标率提升30%以上

**智能咨询助手**：
- 累计解答问题超千个
- 用户好评率90%以上

## 五、生态合作

### 彩翼人工智能联合实验室

与**广东南方信息安全产业基地有限公司**联合打造，构建"场景牵引-技术驱动-产业赋能"的产学研用闭环：
- 三大研发支柱：系列智能体研发、行业样本数据库建设、数据治理及标注技术工具研发
- 双主任负责制、7人管理委员会、五大核心研发组别
- 三年合作周期，分"基础搭建-能力完善-产业化落地"三阶段

### 战略合作生态

- 与全国**26家单位**签署战略合作协议
- 联合**30余家机构**共建采购行业智能体应用生态联盟
- 与广州市白云区智慧城市管理产业促进会签订智能体应用服务协议
- 与广州移动达成合作意向
- 为广州市公安局提供免费试用服务并签订备忘录
