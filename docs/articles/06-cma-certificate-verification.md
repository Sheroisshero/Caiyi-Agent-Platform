## 一、背景：CMA证书查验的痛点

在政府采购，特别是**信息化项目、医疗设备、检验检测服务**等品类的采购文件中，经常要求供应商提供**CMA证书**（检验检测机构资质认定证书）作为资格条件或评分项。

### 什么是CMA证书？

CMA（China Metrology Accreditation）是**检验检测机构资质认定**，是根据《中华人民共和国计量法》的规定，由省级以上人民政府计量行政部门对检验检测机构的基本条件和能力是否符合法律、行政法规规定以及相关技术规范或者标准实施的评价和承认活动。

取得CMA证书的检验检测机构，可以在其检验检测报告上使用CMA标志，其出具的检验检测报告具有法律效力。

### 传统查验方式的痛点

| 痛点 | 具体表现 |
|------|---------|
| **查验效率低** | 人工登录市场监管总局网站逐一查询，每份证书需数分钟 |
| **信息易造假** | 供应商可能提供伪造、变造的CMA证书，人工难以辨别 |
| **状态难核实** | 证书可能已过期、被暂停、被撤销，人工查询不及时 |
| **范围不匹配** | 证书的检验检测能力范围可能不覆盖项目要求，人工核对困难 |
| **批量查验难** | 投标供应商数量多时，逐一查验工作量巨大 |
| **留痕不完整** | 查验过程缺乏系统记录，事后追溯困难 |

## 二、解决方案：CMA证书"一单一库"实时查验

彩翼平台在采购文件合规检测智能体中，新增**CMA证书"一单一库"实时查验能力**，实现CMA证书的自动化、批量化、实时化查验。

### "一单一库"是什么？

| 概念 | 说明 |
|------|------|
| **一单** | 每一份CMA证书的详细信息，包括证书编号、机构名称、发证机关、有效期、检验检测能力范围等 |
| **一库** | CMA证书数据库，汇聚全国检验检测机构的CMA证书信息，支持实时查询和验证 |

### 核心能力

```
CMA证书上传/OCR识别
        ↓
证书信息自动提取（编号/机构/有效期/能力范围）
        ↓
实时对接CMA证书数据库查验
        ↓
┌─────────────┬─────────────┬─────────────┐
│ 真伪验证      │ 状态核实      │ 范围匹配      │
│ 是否真实有效  │ 是否在有效期  │ 能力范围是否  │
│             │ 是否被暂停/撤销│ 覆盖项目要求  │
└─────────────┴─────────────┴─────────────┘
        ↓
查验报告生成（含查验时间、查验结果、证据截图）
        ↓
结果留痕，支持事后追溯
```

## 三、功能详解

### 1. CMA证书OCR智能识别

- 支持CMA证书图片/PDF的自动上传
- OCR识别证书关键信息：
  - 证书编号
  - 机构名称
  - 发证机关
  - 发证日期
  - 有效期至
  - 检验检测能力范围（附表）
- 识别结果带置信度，低置信度标记人工复核

### 2. 实时真伪验证

- 自动对接全国检验检测机构资质认定数据库
- 根据证书编号和机构名称实时查询
- 验证证书是否真实存在
- 识别伪造、变造证书
- 输出验证结果：真实/疑似伪造/查无此证

### 3. 状态实时核实

- 核实证书当前状态：
  - 有效（在有效期内）
  - 即将过期（有效期不足3个月）
  - 已过期
  - 已暂停
  - 已撤销
- 状态异常自动预警
- 支持证书有效期倒计时提醒

### 4. 检验检测能力范围匹配

- 自动提取CMA证书的检验检测能力范围（附表内容）
- 与采购项目要求的检验检测项目进行比对
- 判断证书能力范围是否覆盖项目要求
- 输出匹配结果：
  - 完全覆盖
  - 部分覆盖（列出未覆盖项）
  - 不覆盖
- 为资格审查和评分提供精准依据

### 5. 批量查验

- 支持多份CMA证书批量上传、批量查验
- 适用于投标供应商数量多的场景
- 批量生成查验汇总表
- 大幅提升审查效率

### 6. 查验报告与留痕

- 每份证书生成独立的查验报告
- 报告包含：
  - 证书基本信息
  - 查验时间
  - 查验结果（真伪/状态/范围匹配）
  - 数据库查询截图（证据留存）
  - 查验人员
- 所有查验记录系统留存，支持事后追溯和审计

## 四、技术实现

### 1. OCR识别技术

- 基于大语言模型的多模态OCR能力
- 针对CMA证书格式优化识别模型
- 支持证书附表（检验检测能力范围）的结构化提取
- 表格识别准确率95%以上

### 2. 数据对接技术

- 与市场监管总局检验检测机构资质认定数据库对接
- 支持API实时查询
- 查询结果自动解析和结构化
- 查询频率控制，避免对官方系统造成压力

### 3. 智能匹配算法

- 检验检测项目名称的语义匹配
- 支持同义词、近义词、上下位词匹配
- 匹配结果带置信度
- 模糊匹配结果标记人工复核

### 4. 与合规检测智能体的集成

CMA证书查验能力作为采购文件合规检测智能体的一个功能模块，与其他检测能力协同工作：

- 资格条件审查时，自动查验供应商CMA证书
- 评分项审查时，核实CMA证书评分的合理性
- 投标文件审查时，批量查验所有供应商的证书
- 查验结果纳入合规检测报告

## 五、应用场景

### 场景一：采购文件编制阶段

- 编制采购文件时，设置CMA证书要求
- 智能体自动评估要求的合理性：
  - 项目是否确实需要CMA证书
  - 要求的检验检测能力范围是否合理
  - CMA证书作为资格条件还是评分项
- 避免不合理的CMA证书要求构成排他性条款

### 场景二：投标文件资格审查阶段

- 投标截止后，批量上传所有供应商的CMA证书
- 智能体自动批量查验：
  - 证书真伪
  - 证书状态（有效期/暂停/撤销）
  - 能力范围匹配
- 输出资格审查结果，识别不符合要求的供应商
- 查验结果留痕，支持质疑投诉应对

### 场景三：评分阶段

- 评审时，核实供应商CMA证书的评分依据
- 避免因证书造假或状态异常导致的评分错误
- 为评审专家提供客观、准确的证书信息

### 场景四：监管抽查阶段

- 监管部门对采购项目进行事后抽查时
- 快速查验相关供应商的CMA证书
- 识别供应商造假行为
- 为行政处罚提供证据支撑
